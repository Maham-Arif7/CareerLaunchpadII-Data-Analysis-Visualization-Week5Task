# Financial Performance Dashboard using Power BI

## Project Overview

This project was developed as part of the **Career Launch Pad – Data Analysis & Visualization Program (Week 5 Task)**. The objective was to create a complete interactive Power BI dashboard by importing, cleaning, transforming, analyzing, and visualizing financial data.

The dashboard was built using Microsoft's **Financial Sample Dataset**, which contains sales, profit, product, discount, market segment, and country-related information. The final dashboard provides a clear overview of business performance through KPIs, interactive filters, charts, and summary tables.

---

## Objectives

The main objectives of this project were:

- Import and analyze a real-world business dataset in Power BI.
- Perform data preparation and transformation.
- Create DAX measures and KPIs.
- Build meaningful visualizations for business insights.
- Design a single interactive dashboard for decision-making.
- Apply filtering and slicing techniques for dynamic analysis.

## Dashboard Visualizations

The following visualizations were created:

### 1. Sales by Product
Shows product-wise sales performance and identifies top-selling products.

### 2. Profit by Segment
Compares profitability across customer segments such as Government, Enterprise, Midmarket, Small Business, and Channel Partners.

### 3. Monthly Sales Trend
Displays changes in sales performance across different months.

### 4. Sales Distribution by Segment
A donut chart showing each market segment's contribution to total sales.

### 5. Profit by Country
Compares profit generated from different countries.

### 6. Detailed Sales Summary
A tabular view containing sales, profit, units sold, and discount information for detailed analysis.
